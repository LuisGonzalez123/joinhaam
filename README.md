# joinhaam

Public site for haam. GitHub Pages hosts it until it moves to joinhaam.com.

Pages:

- `/` home
- `/privacy/` privacy policy
- `/terms/` terms of use

## Publish

GitHub → this repo → **Settings → Pages**

- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/ (root)**
